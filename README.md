# MindHaven 🕊️🌿

**"A gentle place for difficult days."**

A safe digital sanctuary for mental wellness and emotional support. MindHaven provides a calming, non-judgmental space for self-understanding, coping tools, and mental health education.

## ⚠️ Important Disclaimer

**MindHaven is NOT:**
- A therapy replacement
- A medical diagnosis platform
- A crisis hotline

**MindHaven IS:**
- A safe digital sanctuary
- An emotional support toolkit
- A mental wellness learning platform
- A calm space for self-understanding
- A gentle companion during hard moments

If you are in crisis, please contact emergency services or a crisis hotline in your country.

## ✨ Features

### 🏠 Safe Daily Dashboard
- Gentle daily mood check-in
- Emotional weather tracking
- Tiny daily support suggestions
- Daily encouragement messages
- Quick access to coping tools

### 🧠 Mental Health Learning Hub
- Educational content about anxiety, depression, loneliness, ADHD, OCD, and stress
- ELI10 (Explain Like I'm 10) mode for simpler explanations
- Compassionate, non-textbook approach
- Links to relevant coping tools

### 🧰 Coping Toolkit
- **Panic Relief Mode**: Immediate calm for overwhelming moments
- **Calm Down Mode**: Beautiful sanctuary space with ambient sounds
- **Overthinking Breaker**: Gentle thought reflection tool
- **Low Energy Mode**: Tiny goals for difficult depression days
- **Loneliness Companion**: Connection support and reflection prompts
- **Breathing Guide**: Multiple breathing patterns (4-7-8, Box, Simple)
- **Grounding Exercise**: 5-4-3-2-1 technique

### 🧘 Calm Space
- Ambient sound options (Rain, Forest, Ocean, Fireplace, Night Sky)
- Breathing visualizer with calming animations
- Mindful quotes
- Web Audio API for generated ambient sounds (no external files needed)

### 📔 Private Journal
- Daily writing prompts
- Private localStorage storage
- Mood tracking integration
- Journal history and search
- Beautiful cozy writing UI

### 📊 Emotional Insights
- Gentle pattern recognition
- Mood trend visualization
- Personalized suggestions based on patterns
- No clinical diagnosis language

### 🚨 Crisis Support
- Immediate crisis resources
- International crisis hotline directory
- Safety planning prompts
- Gentle grounding for crisis moments
- Trusted contact reminder

### 🎮 Gentle Achievement System
- Celebrates tiny wins (no toxic productivity)
- Achievements for check-ins, journaling, coping tool usage
- Gentle notifications
- Progress tracking

### 🔎 Smart Search
- Search across all content
- Typo tolerance (fuzzy matching)
- Quick access to popular topics

### ⚙️ Settings
- Dark/Light mode
- Reduced motion mode
- Text size adjustment
- Ambient sounds toggle
- Data export/import
- Privacy controls

## 🎨 Design Philosophy

MindHaven is designed to feel:
- **Safe** - Warm, calming colors and gentle interactions
- **Calm** - Slow animations, no overstimulation
- **Human** - Compassionate language, no toxic positivity
- **Gentle** - No pressure, no guilt, no shame
- **Accessible** - Large touch targets, reduced motion support

MindHaven is built mobile-first with:

## 🚀 Getting Started

### Local Development

1. Clone or download the repository
2. Open `index.html` in a web browser
3. Or use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```
4. Navigate to `http://localhost:8000`

### GitHub Pages Deployment

1. Push the repository to GitHub
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. Your site will be live at `https://username.github.io/MindHaven`
